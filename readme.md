# Aula 08 — CRUD de Tarefas no React (21/10/2026)

## ✅ O que eu aprendi
Aprendi a criar um CRUD de tarefas com React, permitindo cadastrar, listar, concluir, pesquisar e excluir tarefas.

## 🧩 Principal dificuldade
Minha principal dificuldade foi conectar as funcionalidades com a API e tratar os erros nas requisições.

## 🔧 Como eu resolvi
Utilizei as funções da API para gerenciar as tarefas e implementei a busca e a confirmação antes de excluir.

## 💡Observações (opcional)
Aprendi a importância de organizar o código e melhorar a experiência do usuário com mensagens de erro e confirmações.
