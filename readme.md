# Aula 07 — Tela de Login e Registro no React (14/10/2026)

## ✅ O que eu aprendi
Eu aprendi como criar uma tela de login e cadastro usando React, Vite e TypeScript. Entendi como fazer o usuário preencher os campos de e-mail e senha, enviar os dados para o back-end e utilizar autenticação com JWT para acessar o sistema.

## 🧩 Principal dificuldade
Minha principal dificuldade foi conectar a tela de login com o back-end e entender como funciona a autenticação do usuário, principalmente o envio dos dados para a API e o tratamento de erros quando o login ou cadastro não dá certo.

## 🔧 Como eu resolvi
Seguindo as etapas da aula, criando o formulário de login e cadastro no React e utilizando chamadas à API para enviar os dados. Também foi necessário configurar o back-end para validar as informações, proteger as rotas com JWT e permitir que cada usuário acesse suas próprias tarefas.

## 💡Observações (opcional)
Aprendi que a autenticação permite controlar o acesso ao sistema e que o token JWT é utilizado para identificar o usuário nas requisições protegidas. Também entendi a importância de validar os dados e armazenar as senhas de forma segura, utilizando hash.
